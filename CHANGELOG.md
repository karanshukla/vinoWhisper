## [Unreleased]

### 🚀 Features

- `vinowhisper-doctor` now checks the userspace half of the NPU stack: the
  level-zero backend and the graph compiler, each reported with the version
  string embedded in the library itself. This runs whether or not the NPU
  enumerated, because the two failures it catches both leave the device
  visible and fail later inside `compile_model()`. A missing
  `libopenvino_intel_npu_compiler.so` (which no distro packages) prints the
  extraction steps; a soname symlink reverted to an older backend by a package
  reinstall prints the `ln -sf` that undoes it.

## [0.2.0] - 2026-08-13

The release that stops assuming it is running on the machine it was written on.

### 🚀 Features

- Automatic device selection (NPU → GPU → CPU) with a loud, unmissable warning
  wherever it lands below the NPU: the server log, `/health`, a red panel border
  and a `⚠` line on the status bar, and `vinowhisper-doctor`.
- `vinowhisper-setup`, a guided install that checks each step first, phrases
  every fix in the local distro's package names, and generates the systemd
  units against the paths that actually exist — the checked-in unit used to
  hardcode `~/Development/vinoWhisper`.
- `scripts/install.sh`, a one-command bootstrap: uv, checkout, `uv sync`, then
  the wizard.
- PulseAudio capture backend (`parec`), so the tool runs on machines that never
  moved to PipeWire. Per-application `--target` stays PipeWire-only, and says so
  rather than capturing the wrong thing.
- Distro awareness for eight families (Fedora, Debian/Ubuntu, Arch, openSUSE,
  Alpine, Gentoo, Void, NixOS): package names, install commands, and NixOS
  getting configuration advice instead of an imperative command that would not
  persist.
- NPU diagnosis that goes past "no NPU": the `/dev/accel` node, its permissions,
  the `intel_vpu` module, and then the userspace driver package for this distro
  with Intel's release page as the authoritative fallback.
- Two model exports, because the export is device-specific — the
  `--disable-stateful` NPU export cannot run on CPU at all.
  `scripts/convert_model.sh --variant npu|stateful|both`.
- `vinowhisper-doctor --json` for bug reports, `--no-probe` to skip the live
  level capture, and `--version` on every command.

### 🐛 Bug Fixes

- The default sink is now discoverable without `pactl`, by reading PipeWire's
  own `default.audio.sink` metadata — a PipeWire install without
  `pipewire-pulse` was previously unusable for want of one string.
- The server no longer dies inside the pipeline constructor on a mismatched
  model export. It names the variant, the directory and the command to fix it.

### 🧪 Tests

- A test suite, which this project deliberately did not have. 100+ tests, none
  of which need an NPU, an audio server or OpenVINO — every caption bug from the
  2026-08-06 and 2026-08-07 reviews is now a fixture.

### 👷 CI/CD

- CI on 3.11/3.12/3.13: ruff, ruff format, mypy, pytest, shellcheck.
- A weekly dependency canary, kept off the pull-request path: the OpenVINO
  nightly wheels are pruned upstream on their own schedule, so gating PRs on
  them means red CI for reasons unrelated to the change.
- Tag-driven releases, Bandit scanning to code scanning, Renovate, issue and
  PR templates, MIT licence, contributing and security policies.

## [0.1.0] - 2026-08-07

Pre-changelog. The live captioning loop itself: continuous PipeWire capture into
a ring buffer, a socket-activated NPU transcription server with self-idle-exit,
LocalAgreement-2 stitching of overlapping windows, the Rich status bar, session
record/replay, and `vinowhisper-doctor`. See the README and the design doc for
that history.
